# Jalur Praktik Frontend

!!! note "AI Generated"

    Urutan dari cek API ke Vue diperbarui dengan bantuan AI.

Mulai dengan menampilkan data yang sudah diketahui, lalu ambil data yang sama bentuknya dari API. Urutan ini membantu kita memeriksa tampilan sebelum menambahkan permintaan jaringan.

1. Pelajari elemen halaman dan state UI di [Web Basics](web-basics.md).
2. Tampilkan satu pembacaan sensor di [JavaScript untuk Frontend](javascript.md).
3. Periksa tipe data respons di [TypeScript untuk Frontend](typescript.md).
4. Jalankan [Frontend Mini](../hands-on/frontend-mini.md) untuk memeriksa endpoint `/health` dari browser.
5. Pelajari komponen dan data reaktif di [Vue Basics](vue-basics.md).
6. Ikuti [Integrasi API](api-integration.md).
7. Jalankan [dashboard Vue](../hands-on/dashboard-hands-on.md#jalankan-dashboard-vue).
8. Cocokkan ID pembacaan di Vue dengan respons POST dan baris PostgreSQL.

Pada praktik terakhir, pastikan backend mengizinkan origin frontend melalui CORS. Saat request gagal, periksa alamat API, status response, dan log server.
